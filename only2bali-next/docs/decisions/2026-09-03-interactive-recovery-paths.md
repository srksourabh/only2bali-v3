# Interactive recovery paths remain explicit and trip-specific

When marketplace offers, provider payout setup, payment gateways, OTP delivery, or itinerary generation depend on asynchronous or external state, the UI must expose loading, empty, unavailable, and degraded states instead of appearing inert. Destination CTAs route through canonical destination pages; provider payment-method links terminate at the vendor-authorized payout form; external SMS and Stripe requests use the 1.5-second provider budget. The planner's curated fallback is a product path, so it deterministically cycles every matched interest before repetition and carries the submitted brief into each activity day. Live OTP and Stripe still require legitimate deployment secrets; missing credentials remain fail-closed and visible through `/api/health`.
