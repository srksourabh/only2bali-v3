# ADR 002 - Provider Marketplace And Payment Boundary

Only2Bali now treats provider inventory as moderated marketplace content: providers can maintain profile details, addresses, service listings, media, events, offers, and payout details, but traveler-facing changes remain pending review until the platform approves them. Traveler requests can be published to verified providers for bids only from signed-in travelers with verified mobile sessions; pre-booking chat masks direct contact attempts so the booking and payment stay on-platform. Traveler checkout is recorded in INR through a server-created gateway order, while provider disbursement is tracked separately with its own settlement currency, normally IDR, so collection and payout can be reconciled without storing card, UPI, or full bank account data.
